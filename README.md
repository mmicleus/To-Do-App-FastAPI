# To-Do-App-FastAPI

A personal to-do app built with FastAPI and a plain HTML, CSS, and JavaScript frontend.

## Run locally

Start the API from the project directory:

```powershell
uv run fastapi dev main.py
```

Open the address printed by FastAPI (usually `http://127.0.0.1:8000`). The frontend is served by the same app, so API requests and the UI use the same origin. Create an account, sign in, and manage tasks from the workspace.

The API documentation is available at `/docs`.
